# Нотатки щодо перевірки формату

| Що | Де | Стан / правило |
|---|---|---|
| Порядок байтів, поля 41-байтового заголовка | `Format.WriteHeader/ReadHeader` | звірено з еталонами: magic4 ver1 idx2 count2 salt16 nonce12 cipher_len4, big-endian |
| Структура payload (6 + таблиця файлів + блоки по 15) | `Format.WritePayload/ReadPayload` | звірено з еталонами: file_count2 reserved2=0; файл: name_len2 name size4 crc4 type1 strategy1; block_count2; блок: file_idx2 seq4 raw4 coded4 flags1 |
| Таблиця файлів у кожному томі чи лише в першому | `ArchiveService.Pack` | у кожному томі — файли, чиї блоки в ньому; порожній файл має один нульовий RAW-блок |
| Порядок біт | `BitIO.cs` | підтверджено декодуванням еталонного блоку: MSB-first |
| Запис довжин Гаффмана | `BlockCodec` | звірено з еталонами: три розріджені таблиці (count u16; symbol u16 + length u8), далі token_count u32 і bitstream_size u32 |
| Блоки незалежні (вікно в межах блоку) | `Lz77` | поточна реалізація обмежує пошук межами блока; остаточно звірити зі специфікацією |
| Побудова nonce | `ArchiveService.SealVolume` | підтверджено еталонами: prefix8 \|\| 0 0 idx(2); лічильник CTR: u32 BE з 1 |
| Що входить у HMAC | `Crypto.Mac` | заголовок \|\| шифротекст |
| Код помилки для невідповідної версії | `Errors.cs` | не підтверджено: у наданому `expected_failures.json` немає тесту на неправильну версію; звірити з FORMAT_SPEC_P2.md, якщо викладач його надасть |
| CRC32 | `Crc32.cs` | підтверджено CRC32 еталонних файлів (zlib/IEEE CRC-32) |
| Формат `labels.csv` | `Classifier.LoadSet` | підтверджено за датасетом викладача: `file,type,type_name,size`; клас береться з другої колонки `type` |
| Цінність блоку для рюкзака | `ArchiveService.Pack` | реалізовано як пріоритет типу × raw_len; для порожнього блока використовується 1, щоб зберегти файл; формулу оцінки потрібно звірити з повною специфікацією |
