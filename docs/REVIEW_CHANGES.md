# Зміни після технічної перевірки

## Виправлено

1. **Класифікатор:** `labels.csv` викладача має колонки `file,type,type_name,size`. Раніше програма брала останню колонку `size` замість `type`, тому мітки класів були неправильними. Тепер читається друга колонка, а некоректні рядки, дублікати та відсутні файли викликають зрозумілу помилку.
2. **Формат payload:** виправлено порядок і ширину полів за еталонними архівами: `file_count`, `reserved=0`, записи файлів із 32-бітним розміром, `block_count`, записи блоків.
3. **Кодування блоків:** замість щільних 4-бітних таблиць довжин реалізовано розріджені таблиці канонічного Гаффмана, `token_count`, довжину bitstream і MSB-first потік.
4. **Порожні файли:** тепер вони зберігаються як один нульовий RAW-блок, як в еталоні викладача.
5. **Навчання:** перевіряються розміри датасетів і діапазон міток; модель обирається за valid macro-F1. Якщо результат нижчий за `F1_min`, модель зберігається для аналізу, але команда повертає код 5.
6. **CLI та валідація:** додані перевірки відсутніх аргументів, відсутньої моделі, некоректного `block_size` і невідповідності довжин блочних даних.

## Регресійні тести

У `tests/SmartArchiver.Tests/Fixtures/` додано еталонні архіви викладача. Тести перевіряють:
- усі п'ять однокомпонентних еталонів;
- багатотомний еталон із трьох томів у зворотному порядку;
- шість негативних прикладів і очікувані коди помилок;
- декодування еталонного стисненого блоку;
- формат payload та порожній файл;
- правильне читання колонки `type` у `labels.csv`.

## Межі перевірки

Незалежна перевірка Python підтвердила HMAC, розшифрування, відновлення блоків, розміри та CRC32 для всіх еталонних архівів `ref_01`–`ref_06`. Але .NET SDK у середовищі редагування відсутній, тому C# solution не було скомпільовано й `dotnet test` не запускався. Це обов'язково потрібно зробити локально або через GitHub Actions.

Файл `FORMAT_SPEC_P2.md` не був у наданих архівах. Через це код помилки для невідповідної версії та деякі правила, яких немає в еталонних файлах, залишаються для звірки з повною специфікацією. Експерименти та письмовий звіт за методичкою також не створені цими змінами.
